# 마트 선택 홈 설계

## 목적과 범위
앱의 첫 화면은 “어디서 장을 볼까요?”라는 중앙 문구와 마트 선택이다. 마트를 추가하거나 선택하면 기존의 살 것/고민 중, 빠른 입력, 구매 체크, 룰렛 화면으로 들어간다. 사용자가 계획 수립 후 즉시 구현과 APK 제작을 요청했으므로 별도 승인 대기 없이 진행한다. 커밋은 사용자 허락 전까지 금지한다.

## 데이터와 흐름
마트 하나는 기존 ShoppingList 하나에 대응한다. 이 앱에서 마트별 장보기 목록은 하나이며 새로운 중첩 목록이나 DB 테이블은 필요하지 않다. 기존 목록은 동일한 ID와 품목을 가진 마트 카드로 보존하며 이름을 변경할 수 있다. Room schema 3, 패키지 com.minwoo.jangbogi, minSdk 26, targetSdk 34 유지.

홈(home) → 장보기(shopping/{listId}) → 살림 계획(plan). 장보기 상단 뒤로가기와 시스템 뒤로가기는 마트 홈으로 돌아간다. 상단 마트 이름은 다른 마트를 선택하는 시트를 연다. 선택은 저장 성공 후 이동하며 마트별 입력 초안을 SavedStateHandle에 유지한다. 앱을 새로 실행하면 항상 마트 홈이고 화면 재생성은 현재 위치를 복원한다.

## 디자인
기존 화이트·블루 팔레트와 다크 테마를 유지한다. 상단 작은 장보기 브랜드, 가운데 마트 벡터 일러스트와 두 줄 제목, 보조 문구. 등록된 마트는 넉넉한 둥근 카드로 이름, 남은 구매 수, 고민 중 개수, 완료 진행률, 진입 화살표와 별도 더보기 메뉴를 제공한다. 빈 홈은 화면 중앙에 큰 일러스트·제목·도움말·마트 추가 버튼을 배치한다. 목록이 길어지면 스크롤하고 하단 마트 추가 버튼은 계속 접근할 수 있다.

마트 추가/이름 변경: 하단 시트, 마트 이름 필드, 빠른 이름 제안, 명확한 저장 버튼, 공백 이름 금지, 중복 제출 방지, 저장 중 표시와 실패 시 재시도. 취소는 데이터를 생성하지 않는다. 삭제는 품목도 삭제됨을 알리는 확인창과 실행 취소를 제공한다.

## 움직임과 접근성
화면 진입은 300ms 이내 수평 슬라이드+페이드, 뒤로가기는 반대 방향. 홈 일러스트/제목은 짧은 진입 애니메이션, 카드와 진행률은 부드럽게 반응한다. 무한 애니메이션과 불필요한 지연 없음. 시스템 애니메이션 0 설정을 따른다. 최소 터치 영역 48dp, 이름 줄바꿈, 큰 글씨에서 세로 배치, 320dp 폭·글씨 200%·라이트/다크·키보드 겹침 확인.

## 검증과 배포
실제 Android 계측 테스트로 첫 홈, 마트 선택/품목 분리, 추가/공백/취소, 이름 변경/삭제 Undo, 재생성·입력 초안, 기존 룰렛 흐름을 검사한다. JVM 테스트, lint, debug/release 빌드와 서명을 검증하고 전용 QA 에뮬레이터에서 캡처한다. versionName 1.4.0, versionCode 7. 기존 PC debug keystore 서명을 유지하고 루트에 장보기_v1.4.0.apk를 제공한다.
