# v1.2.0 장보기 화면 검증

2026-09-27 · `main` · Android 14(API 34) QA 에뮬레이터 · 360dp/320dp

## 자동 검증

- `:app:assembleDebug :app:assembleRelease :app:testDebugUnitTest :app:lintDebug` 성공.
- JVM 단위 테스트 39개 통과, 실패 0개.
- Android 14 에뮬레이터 계측 테스트 5개 통과: v1/v2 → v3 마이그레이션, 목록별 완료 항목 실행 취소, 삭제된 목록 복원 방지, 이름을 공유하는 물건의 계획 동기화.
- Lint 오류 0개. 경고 55개는 주로 의존성 버전·미사용 리소스 관련이다.
- 릴리스 APK의 `versionCode=5`, `versionName=1.2.0`, `minSdk=26` 및 v2 APK 서명 검증. 기존 `장보기_v1.1.2.apk`와 서명 인증서가 같다.

## 기기에서 확인한 흐름

- 새 설치: 목록 생성 대화상자 없이 ‘무엇을 살까요?’와 입력창이 열림. 첫 물건 입력 시 목록 자동 생성.
- 고민 중을 첫 항목으로 입력해도 구매 진행률에 포함되지 않고 해당 탭이 유지됨. ‘살래요’로 이동하면 살 것 개수와 구매 진행률이 갱신됨.
- 기존 `v1.1.2`에 `eggs ×3`(미완료), `milk ×2`(완료)를 만든 뒤 `v1.2.0` APK로 덮어 설치. 두 물건·수량·완료 상태와 `1/2` 진행 상태가 보존됨.
- 고민 항목 보관, 살 것으로 이동, 구매 체크, 앱 강제 종료 후 재시작까지 상태 유지.
- 새 목록 초안 중 이전 활성 목록을 삭제하고 초안을 취소해도 남은 목록으로 복귀.
- 320dp/360dp, 글씨 200%, 라이트/다크 모드에서 주 동작·메뉴·입력창 표시 확인. 200% 글씨의 좁은 화면에서도 더보기에서 ‘살림 계획’을 열 수 있음.

## 범위

`v2 → v3` 실제 APK 업그레이드와 테스트 DB 기반 `v1/v2 → v3` Room 마이그레이션을 확인했다. `v1 → v3` 실제 APK 업그레이드, Compose 화면 자동화 테스트, TalkBack 음성 안내는 이번 QA에서 실행하지 않았다.
